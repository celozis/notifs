# Визуальный эталон Notifs

Базовый графитово-янтарный вид и поведение Q1–Q46 согласованы. 19 ноября пользователь назначил дополненный прототип целевым для Windows-приложения и подтвердил публикацию подробных тикетов. Основное WPF-приложение ещё не приведено к этому виду; [карта реализации](../../../docs/product/implementation-map-2026-11-19.md) распределяет работу.

Закреплённый в тикетах исходный комплект — коммит `f0462998e790e7fd9b4efce4ed8e0a4722875b71` ветки `codex/design-handoff`. Пометки «awaiting visual review» в его manifest/tokens относятся к состоянию на момент подготовки снимков; текущий целевой статус указан выше. Исходники, токены и PNG эталона при публикации тикетов не менялись.

## Открыть и воспроизвести

- [Автономный просмотр](../../../prototypes/ui-concepts/notifs-reference.html): открыть браузером, интернет и Visualize не нужны. Lucide 1.17.0 поставляется локально с лицензией.
- [Образец до grilling](../../../prototypes/ui-concepts/notifs-workspace-prototype.html) сохраняет исходную палитру/компоновку и исторические временные правила.
- [Дополненный фрагмент](../../../prototypes/ui-concepts/notifs-approved-workspace.html) используется для показа в чате.
- Генерация: `python prototypes/ui-concepts/build_reference.py`. Источники дополнений — workspace-additions.js и workspace-additions.css. Генерируются фрагмент, автономный HTML и tokens.json.

Кнопки под макетом — проверочные инструменты, не часть приложения. Данные демонстрационные, исходное время — 18 ноября 2026, 12:00. Автономная версия использует отдельный ключ localStorage `notifs-approved-prototype-v1`, не базу приложения. «Сбросить демо» очищает только этот ключ. В inline-хосте при недоступном хранилище используется память.

## Снимки состояний

Снимки в [screens](screens/) фиксируют демонстрационные состояния. Основной viewport 1060×1240, deviceScaleFactor 1; высота захвата включает макет целиком, поэтому месяц не обрезан. Узкие снимки имеют свою ширину viewport. Образец имеет внешние поля просмотра 24 (8 до 600) и декоративный заголовок 36; при сравнении WPF отделять нативную рамку от содержимого. Точные размеры PNG и SHA-256 источников записаны в [manifest.json](manifest.json), обновляется после проверки командой `python prototypes/ui-concepts/capture_manifest.py`.

| Файл | Что сверять |
| --- | --- |
| tasks.png | Палитра, навигация, колонки, ранги, выбор и действия |
| filters.png | Центральная панель, отбор/порядок, применение/сброс |
| in-progress.png / paused.png | Начало, активное время, пауза/продолжение |
| editor.png / markdown-editor.png | Форма, Markdown, форматирование, личное расписание |
| reminders.png / reminder-editor.png | Сигналы/дела, состояние расписания и форма |
| settings.png | Монитор, сводка, отсрочка, фон |
| week.png / month.png / range.png | Неделя, месяц, диапазон, панель периода |
| notifications.png / check-in.png | Стек, «Скрыть все», типы, «Ещё 30 минут» |
| delete-confirmation.png | Подтверждение удаления |

Результаты интерактивных проверок и контраст — в screens/inspection.json. Воспроизведение: `node prototypes/ui-concepts/inspect_reference.cjs` (Windows, установленный Edge, Node с WebSocket). Создаётся отдельный headless-профиль в `.scratch`, сеть браузера заблокирована, часы фиксированы; личный браузер не используется. Это не доказывает нативную доставку без фокуса, мониторы, трей или SQLite — они проверяются в WPF-тикетах.

## Граница демонстрации

Прототип проверяет формы, отбор, порядок, черновики, занятия и видимость уведомлений. Фоновый планировщик, мониторы, автозапуск и трей не реализованы: уведомления типов вызываются кнопками под макетом. Правила планировщика — в [спецификации](../../../docs/product/design-spec-2026-11-18.md) и тикетах.

При реализации также обязательны пустые списки/результаты, отсутствие выбора/оценки/дедлайна, ошибки полей/хранения с сохранением ввода, длинные названия/Markdown, большие списки, 150%/200% DPI, reduced-motion, недоступный дополнительный монитор. Новые состояния используют существующие токены/контролы без смены направления.
