# Notifs: согласованный дизайн и поведение

Статус: ответы Q1–Q46 и общее понимание подтверждены пользователем 19 ноября 2026 года («Да, вроде мы друг друга поняли»). Продуктовое поведение утверждено. [Дополненный визуальный эталон](../../design-system/notifs/reference/README.md) подготовлен для отдельной оценки новых экранов. WPF-реализация и GitHub Issues пока не обновлены.

Источник решений: [журнал интервью](design-interview-2026-11-18.md). Термины: [CONTEXT.md](../../CONTEXT.md). Исходная продуктовая картина: [интервью 17 ноября](interview-summary.md). Здесь собраны текущие правила без отвергнутых предложений; журнал сохраняет их происхождение.

## Визуальный эталон и граница готовности

Исходный одобренный образец: [notifs-workspace-prototype.html](../../prototypes/ui-concepts/notifs-workspace-prototype.html), SHA-256 `8871a31d90648974bbedbed14b26028c810389454f21f38c4f1030f167893658` на начало интервью. Он задаёт выбранное оформление; новые правила интервью ещё требуется в него внести.

- Графитовые поверхности и янтарный акцент; выбранная палитра и типографика берутся из образца, а не генерируются заново.
- Постоянная левая навигация: «Новая задача», «Мои задачи», «В процессе», «Календарь», «Напоминания», «История», «Настройки».
- При обычной ширине список и подробности занимают примерно по половине рабочей области. Создание/редактирование заменяет содержимое этой области; отдельного окна редактора нет.
- При узком окне — список либо подробности с явным возвратом. Навигация остаётся слева, при необходимости сокращается до иконок с подсказками. Списки и длинные описания прокручиваются внутри своих областей.
- Вся карточка задачи выбирается нажатием; галочка выполнения — отдельное действие. Состояния наведения, нажатия, фокуса и выбора относятся ко всей карточке.
- Ранг показан буквой в цветном заполненном квадрате: S красный, A оранжевый, B золотистый, C жёлто-зелёный, D зелёный. Цвет не заменяет букву.
- «Удалить» — справа от остальных действий задачи. Подтверждения и панель календарного периода находятся поверх затемнённой рабочей области, внутри основного окна.
- Клавиатура, видимый фокус, читаемый контраст, длинные строки и масштабирование Windows входят в приёмку. Детали размеров и состояний фиксируются в дополненном визуальном эталоне.

MASTER.md и tokens.json обновлены по графитово-янтарному образцу. Исходный прототип сохранён как исторический; формы, фильтры и стек добавлены в notifs-approved-workspace.html. Автономный notifs-reference.html открывается без интернета. Новые экраны ещё ожидают визуальной оценки; их подготовка не означает готовность настоящего приложения.

## Задачи, редактор и удаление

- Обычные задачи сохраняют название, Markdown-описание, исходное создание, необязательные дедлайн и полную оценку, ранг. Исходные требования к локальному хранению, возрасту и концу дня без точного времени сохраняются.
- «Готово» не убирает задачу немедленно из видимого списка: карточка приглушается, название зачёркивается, видны галочка и состояние выполнения. Активные уведомления задачи прекращаются.
- Фильтр состояния: «Все / Не сделаны / Сделаны», исходно «Все». Карточка, переставшая соответствовать состоянию фильтра после действия, остаётся видимой на прежнем месте до следующего явного переключения фильтра или раздела.
- При обычном обновлении списка сначала невыполненные, затем выполненные. Исходно невыполненные идут по срочности, выполненные — от недавно завершённых к старым. «История» — отдельный вход к тем же выполненным задачам, без копий.
- «В работу» возвращает задачу в невыполненные, не начинает занятие автоматически.
- Один черновик новой задачи и по одному для каждой редактируемой задачи сохраняются при навигации и между запусками. Сохранённая задача меняется только по «Сохранить». «Отбросить изменения» относится только к текущему черновику.
- Описание редактируется как Markdown с форматированным просмотром внутри редактора. При выделении ввод `*`, включая Shift+8, оборачивает текст звёздочками и сохраняет выделение. Повторный ввод добавляет следующую пару. Без выделения звёздочка вводится обычно.
- Ctrl+B/Ctrl+I и кнопки переключают соответствующее форматирование выделения. Одно действие форматирования отменяется одним Ctrl+Z.
- Удаление требует подтверждения и убирает задачу из списков/истории/календаря, прекращая её занятие и уведомления.
- Один общий слот восстановления последнего удаления, включая удаление повторяющегося расписания. Доступен до следующего удаления либо использования восстановления, переживает перезапуск; отдельной корзины нет.
- Восстановление задачи возвращает данные, черновик, исходное создание и состояние выполнения; занятие возвращается на паузе.

## Фильтры и сортировка

- «Фильтры и сортировка» открывает панель поверх текущего экрана в том же окне.
- Сортировка: исходная «По срочности», по рангу, полной оценке, дедлайну и созданию. Для сортировки по полю доступны оба направления.
- Выбранное поле заменяет срочность внутри групп выполнения; невыполненные остаются выше выполненных. Отсутствующие дедлайн/оценка идут в конце соответствующей сортировки при обоих направлениях. Равенства сохраняют устойчивый порядок.
- Исходная срочность: просроченные по самому старому дедлайну; остальные со сроком по наименьшему запасу `дедлайн − сейчас − полная оценка`, затем ближайшему дедлайну, затем рангу; без дедлайна — в конце, созданные раньше выше. При отсутствии оценки вычитается ноль. Полная оценка не уменьшается от работы над задачей.
- Фильтры: несколько рангов; диапазон полной оценки в минутах/часах либо «Без оценки»; диапазон дат дедлайна либо «Без дедлайна»; диапазон дат создания. Разные критерии соединяются И, выбранные ранги — ИЛИ. Границы дат включают день целиком.
- «Применить» применяет весь выбор разом. Закрытие/Escape сохраняет прежние применённые настройки. Кнопка показывает активность отбора и выбранный порядок.
- «Сбросить» возвращает исходные настройки списка текущего раздела, сохраняя выбранные календарные даты.
- «Мои задачи», «В процессе», «История» и «Календарь» запоминают настройки независимо, включая перезапуск.
- В календаре дополнительно «Все / Обычные задачи / Повторяющиеся дела». При отборе по рангу, оценке, дедлайну или созданию обычной задачи повторяющиеся дела исключаются как не имеющие этих полей; панель объясняет это.
- Сводка уведомлений всегда использует исходную срочность; пользовательская сортировка списка её не меняет.

## Занятия и активное время

- «Сел делать» фиксирует фактическое начало. Планового начала нет. Раздел «В процессе» содержит начатые задачи, в том числе на паузе.
- Одновременно активно одно занятие. Начало или продолжение другого ставит предыдущее на паузу; число приостановленных задач не ограничено.
- Активное время — время запущенного занятия за вычетом явных/системных пауз, а не измерение непрерывной занятости. Приложение не выводит из этой отметки, что пользователь не отвлекается.
- «Сделать паузу» сохраняет активное время и остаток до вопроса. «Продолжить» расходует оставшееся время, без нового полного отсчёта. Повторные паузы тоже исключаются.
- «Отменить» снимает ошибочный старт, накопленное активное время и ожидающий вопрос, сохраняя саму невыполненную задачу и её поля.
- Без оценки занятие возможно, но вопрос по времени не назначается. Добавление/изменение оценки рассчитывает остаток как новую полную оценку минус активное время этого занятия.
- Если новая оценка уже исчерпана, у активного занятия вопрос приходит сразу, у приостановленного — после продолжения.
- Фактическое изменение оценки отменяет прежнее откладывание вопроса и пересчитывает его. Удаление оценки отменяет вопрос, сохраняя занятие. Изменение других полей и сохранение той же оценки не запускают вопрос заново.
- Вопрос «Сделал задачу?» приходит один раз при достижении оценки. Закрытие/скрытие не завершает задачу, не ставит занятие на паузу и не назначает повторный вопрос.
- «Ещё 30 минут» назначает следующий вопрос через 30 активных минут от действия, исключая паузы. Дедлайн и полная оценка не меняются.
- Личные напоминания и упоминания в сводке продолжаются во время занятия. Вопрос по активному времени — независимый дополнительный источник.
- В трее и при блокировке Windows занятие продолжается. Сон/гибернация и явный «Выход» ставят его на паузу. После пробуждения/перезапуска требуется «Продолжить»; время отсутствия работающего приложения не начисляется. После аварийного закрытия восстанавливается пауза.
- «Готово» завершает занятие и вопросы, сохраняя дату последнего начала для календаря. После возврата в работу новый старт начинает отсчёт с нуля и заменяет эту дату. Истории подходов и статистики времени нет.

## Календарь

- Недельный режим: понедельник–воскресенье, переход между неделями, выбор дня/целой недели рядом со списком задач.
- «Открыть календарь» заменяет рабочую область полным месячным обзором. В ячейках видны ранг и начало названия обычных задач; повторяющиеся дела различаются по типу.
- Нажатие дня открывает центральную панель с затемнением, задачами и «Перейти к этому дню». Escape/закрытие возвращает в календарь.
- Произвольный непрерывный диапазон выбирается протягиванием в обе стороны через строки, включая видимые соседние даты. Это хронологический диапазон, не прямоугольник ячеек.
- Клавиатура и поля «С / По» дают альтернативу перетягиванию. Периоды за пределами видимой сетки задаются полями, без автоматического перелистывания при протягивании.
- После выбора диапазона открывается панель его задач. Переход открывает неделю начала, сохраняя выборку всего диапазона и явную подпись дат.
- Основания обычной задачи: создание, фактическое начало последнего занятия, дедлайн, расчётный промежуток без дедлайна, назначенный момент вопроса о результате. Одна задача показана один раз, с отметками всех подходящих оснований.
- Расчётный промежуток без дедлайна — от создания до создания плюс полная оценка, включая все затронутые дни/недели. Занятия и паузы его не сдвигают; это не дедлайн и не основание просрочки.
- Момент вопроса имеет отдельную подпись; на паузе будущий момент не показывается, после продолжения пересчитывается.
- При возвращении сохраняются месяц, период и режим, включая перезапуск. «Сегодня» возвращает к текущему дню и его неделе.
- Выполненные задачи исходно видимы с отметкой; действует фильтр состояния.

## Повторяющиеся напоминания и настройки

- Личное расписание обычной задачи — раскрываемый блок её редактора.
- «Напоминания» содержит простые сигналы и дела с подтверждением; общая форма позволяет выбрать режим. Они не создают копии в «Моих задачах» и не используют занятия.
- Периодическая сводка, монитор и общие параметры доставки — в «Настройках». Все редакторы — в основной рабочей области.
- Сохраняются исходные фиксированные календарные/почасовые расписания и интервал после фактического выполнения. У подтверждаемого напоминания одно текущее невыполненное дело с датой первого пропуска, без очереди долгов.
- Выключение сохраняет текущее дело и его дату, прекращает уведомления, позволяет выполнить дело. При включении старый долг сохраняется; если его нет, но срок прошёл во время выключения, формируется одно дело с первой пропущенной датой и одно уведомление. Старые простые сигналы не воспроизводятся.
- Изменение расписания не сбрасывает текущий долг/дату. Следующие циклы определяются новым правилом. Смена подтверждаемого дела на простой сигнал требует подтвердить снятие текущего долга.
- В календаре видны подтверждаемые дела, прошлые выполнения и известные будущие даты. Будущие даты фиксированного расписания — плановые отметки, не новые долги. Для интервала после выполнения известна только ближайшая дата.
- Простые сигналы не заполняют календарную сетку. Просроченное текущее дело не копируется в каждый последующий день, оставаясь доступным в «Напоминаниях».
- Будущая отметка открывает расписание без досрочного «Готово». Прошлое выполнение относится к фактической дате и сохраняет исходный срок как дополнительное основание.
- Удаление расписания с подтверждением убирает текущее дело, уведомления и прошлые выполнения из календаря; подтверждение сообщает об истории. Восстановление возвращает историю/дело, а расписание оставляет выключенным.
- Обычное откладывание — настраиваемая общая длительность, исходно 30 минут по часам. Не связано с паузами занятия. Отложенное личное напоминание временно исключает задачу из сводки до выбранного момента, но не подавляет независимый вопрос по активному времени.

## Стек уведомлений

- Справа снизу выбранного монитора не более двух полностью читаемых карточек с зазором. Новая появляется снизу, предыдущая смещается вверх; третья вытесняет самую старую. Приоритета по типу нет.
- Полоса «Скрыть все» непосредственно над видимыми карточками, в том числе одной. При пустом стеке скрыта. После удаления одной карточки оставшаяся занимает нижнее место.
- Автоматического исчезновения нет у всех типов карточек. Это отменяет старые 10 секунд.
- Крестик, «Скрыть все» и вытеснение меняют только видимость: не выполняют дело, не ставят занятие на паузу, не откладывают напоминание. Скрытые карточки не возвращаются очередью и не считаются пропущенными для сводки.
- При наведении стек автоматически не перемещается/не вытесняет карточку под мышью. Новые поступления временно ожидают, сохраняются два последних; после ухода указателя стек обновляется. Явные действия работают сразу. Занятие/расписания не останавливаются.
- «Скрыть все» очищает и ожидавшие из-за наведения поступления, но не отключает будущие события расписания.
- «Готово» из любого места убирает отдельные уведомления выполненной задачи/текущего дела; из сводки исчезает только эта строка. Остальные строки остаются, пустая сводка скрывается. Удаление задачи убирает её карточки.
- Откладывание закрывает карточки соответствующего напоминания, сохраняя независимые источники по правилам выше.
- Негромкий звук нового события — не чаще раза в секунду при серии. Сдвиги/скрытие и показ уже ожидавшего события повторно не звучат.
- Постоянная видимость действует, пока приложение работает, включая трей. Сон карточки не закрывает. Полный выход закрывает; после запуска старый видимый стек не восстанавливается. Данные и отсрочки сохраняются, действительно пропущенные события объединяются в одно сообщение.
- Прежние правила отсутствия перехвата фокуса, выбора монитора, полноэкранного режима и звука без показа при недоступном дополнительном мониторе сохраняются. Новый стек должен пройти нативную проверку этих правил заново.

## Проверки, фиксирующие существенные решения

| Сценарий | Ожидаемый результат |
| --- | --- |
| Создана в субботу без дедлайна, оценка 72 часа; выбран понедельник | Задача видна как пересечение всего расчётного промежутка |
| Оценка 40 минут, активно 10, пауза час | После продолжения до вопроса 30 активных минут |
| «Ещё 30 минут», активно 10, пауза час | После продолжения до следующего вопроса 20 активных минут |
| Начать B, пока активно A | A на паузе с сохранённым остатком; B единственная активная |
| Начать задачу с оценкой 10 часов | Её дневные личные напоминания и сводка продолжаются |
| Оценка 40, активно 10, изменить оценку на 60 | Остаток 50 минут; прежняя отсрочка вопроса заменена |
| В «Не сделаны» нажать «Готово» | Карточка остаётся зачёркнутой до следующего явного выбора фильтра/раздела |
| Сортировать по дедлайну в любом направлении | Без дедлайна следуют после задач со сроком |
| Изменить поля панели и закрыть Escape | Прежние применённые настройки не изменились |
