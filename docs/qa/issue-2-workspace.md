# #2 — рабочее окно задач

## Реализовано в коде

- Графит/янтарь из MASTER/tokens, Segoe UI/Consolas, собственные геометрические векторные иконки 18 DIP.
- Постоянная левая навигация 178 DIP; ниже 550 — 58 DIP. Новая задача в навигации, настройки и локальное пространство внизу. Будущие разделы недоступны с поясняющими подсказками.
- Равные колонки с зазором 20, поля 25/30; ниже 850 — одна область с возвратом. Минимальная высота окна 420, создание/изменение в основной рабочей области.
- Локальные создание/изменение/выполнение/возврат. Схема SQLite v1 не меняется: сохранены прежние идентификаторы, создание и Markdown.
- Исходный фильтр «Все», счётчики, явное переключение фильтров и разделов пересчитывает состав/порядок. Выполнение и возврат удерживают строку/место даже после обычного обновления.
- Отдельное действие галочки, состояния всей карточки, зачёркивание и подпись выполнения; безопасный нативный Markdown без загрузки ресурсов.
- Валидация заголовка с сохранением текста, защита повторного сохранения, сообщение об успехе только после SQLite, повтор чтения, сохранение прежнего состояния при ошибке записи.
- Фокус формы, Enter/Space для подробностей, возврат к связанной карточке, доступные имена и подсказки иконок.

Поля дедлайна/оценки/ранга, занятия, постоянные черновики, удаление, расширенные фильтры, расписания, трей и автозапуск остаются за своими тикетами. Несохранённый ввод удерживается только в памяти текущего окна.

## Проверки и ограничения

Статическая проверка XML всех XAML и `git diff --check` выполнены. Это не компиляция XAML/C# и не доказательство поведения WPF.

Сценарный стенд обновлён для реальной временной SQLite с управляемыми часами, сохранности прежних данных, Markdown, дубликатов отправки, удержания выполнения/возврата, повторного открытия, ошибок чтения/записи, клавиатурного открытия/возврата и ширин 1010/768/375/320 DIP. После успешного запуска он создаёт PNG в `.artifacts/ui-qa/`.

Попытка `./build.ps1 -Test` остановилась с сообщением «Нужен .NET 10 SDK» до сборки.

**Не выполнено:** сборка/проверка типов, запуск обновлённых сценариев, проверка реальными мышью/клавиатурой, снятие и сравнение новых PNG, длинные списки в работающем приложении, физический DPI и экранный диктор. SDK .NET 10 отсутствует. Официальный загрузчик зависал, CDN-соединения обрывались; альтернативная браузерная загрузка остановлена инструментом, который не смог надёжно определить URL. Частичный архив SDK не является установленным SDK. Тикет #2 остаётся незавершённым до этих проверок и исправления возможных проблем.

## Визуальный эталон

До реализации просмотрены `tasks.png`, `editor.png`, `width-768.png`, `width-375.png`, `width-320.png`; прочитаны MASTER, tokens, manifest, продуктовые правила и инструкция эталона. PNG использованы как разрешённый тикетом запасной путь просмотра. Прототип не выдаётся за работающее приложение.

Исправлены в коде расхождения старой основы: светлая палитра, верхняя навигация на узком окне, неравные колонки, отдельное окно редактора, ограничение минимальной ширины 760, немедленное исчезновение выполненной карточки, отсутствие фильтра состояния. Сравнение снимков реализации с эталоном **ещё не выполнено**. Для сравнения нужно исключить декоративную рамку и внешние поля просмотра эталона и сопоставить клиентскую область при масштабе 1.
