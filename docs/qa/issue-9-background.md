# #9 — трей, один экземпляр и автозапуск

Проверено 20 ноября 2026 на Windows x64, .NET SDK 10.0.404. Источник: GitHub #9, утверждённые Q1–Q46, `MASTER.md`, состояния `settings.png` и `notifications.png`. Блокер #4 закрыт. Комплект `f0462998` присутствует в истории ветки.

## Реализованный путь

- Крестик скрывает главное окно, сохраняя тот же процесс, редактор, планировщик и карточки. Черновик записывается штатным механизмом; незавершённые операции продолжаются. Обычное сворачивание не завершает программу.
- Янтарный значок с галочкой открывает существующее окно левым кликом; меню содержит «Открыть Notifs» и «Выход». Меню Windows Forms используется нативно, без диагностических элементов в приложении.
- «Выход» останавливает новые опросы/действия уведомлений, дожидается уже начатых действий и опроса, затем закрывает окно, звук и стек. Обычные операции основного окна также защищены существующим запретом закрытия во время записи.
- Один экземпляр на пользователя, Windows-сеанс и профиль данных. Mutex захватывается до создания сервиса SQLite и планировщика; повторный запуск передаёт право foreground и сигнал открытия первому. Профиль `NOTIFS_DATA_DIR` позволяет изолировать проверки от обычных данных.
- «Работа в фоне» в настройках содержит переключатель автозапуска и объяснение трея. Изменения применяются общей кнопкой сохранения. Источник состояния — регистрация Windows, отдельного флага в SQLite нет.
- Запись `Notifs` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` содержит полный, заключённый в кавычки путь `Notifs.App.exe` и `--background`. Фоновый запуск загружает данные даже без `Loaded` главного окна. При отключении запись удаляется. После перемещения программы автозапуск нужно пересохранить из нового места.
- Ошибка регистрации оставляет ввод и прежние настройки SQLite; ошибка SQLite восстанавливает предыдущую регистрацию. Схема базы не менялась, задачи, расписания и отсрочки используют существующее хранение.

## Границы и ручное воспроизведение

Полный выход/повторный запуск и сохранение данных проверены; старый видимый стек не восстанавливается из UI-снимка. Общая обработка пропусков, системный сон, блокировка и сбой относятся к #20; занятия — к #16/#17. Физическая смена DPI и экранный диктор не проверены; 150%/200% здесь — увеличение содержимого. Фактический выход из Windows и новый вход не выполнялись: проверены сама регистрация и запуск приложения с её аргументом. Готовому apphost требуется .NET 10 Desktop Runtime либо самодостаточная поставка (#10); SDK не входит в команду автозапуска.

Запуск: `.\build.ps1 -Run`. Проверки после сборки: `--background`, `--autostart`, `--background-ui` у `tests/Notifs.Scenarios/bin/Release/net10.0-windows/Notifs.Scenarios.dll`; все они входят в полный набор.

Ручной маршрут: создать задачу с близким личным напоминанием → крестик → дождаться карточки → открыть значок → убедиться, что редактор/данные сохранены → запустить приложение ещё раз → проверить одно окно/процесс → включить и сохранить автозапуск, проверить регистрацию, отключить и сохранить → отложить карточку и сразу выбрать «Выход» → запустить заново и проверить задачу/отсрочку. Для проверки фактического запуска при входе Windows отдельно включить автозапуск, сохранить, выйти из сеанса и войти снова.
